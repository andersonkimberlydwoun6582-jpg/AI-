# Launch Checklist

## Domain and deployment

- [ ] Official domain resolves correctly.
- [ ] HTTPS is valid.
- [ ] Preferred host redirects are correct.
- [ ] Preview and platform domains are not used as canonical URLs.
- [ ] Production environment variables are reviewed.

## Crawl and indexation

- [ ] robots.txt matches the launch decision.
- [ ] Sitemap contains only intended indexable canonical URLs.
- [ ] Canonical tags use the official domain.
- [ ] Noindex pages are excluded from indexable sitemaps.
- [ ] Redirects have no loops or unnecessary chains.

## Page quality

- [ ] Titles, descriptions, and H1s are accurate and unique where required.
- [ ] Page intent and keyword ownership are documented.
- [ ] No template residue or unrelated topic contamination remains.
- [ ] Important claims, sources, dates, and versions are checked.
- [ ] Trust and legal pages match actual site behavior.

## Internal links

- [ ] Important pages are reachable through HTML links.
- [ ] No intended indexable page is orphaned.
- [ ] Breadcrumbs are correct.
- [ ] Internal links use canonical destinations.
- [ ] Related-content modules are relevant.

## Multilingual

- [ ] Locale routes and labels are correct.
- [ ] Canonical and hreflang are consistent.
- [ ] Alternate URLs are real equivalents.
- [ ] Incomplete fallback translations remain non-indexable.
- [ ] Language switching works on representative pages.

## Experience and performance

- [ ] Mobile and desktop layouts have no blocking overflow.
- [ ] Navigation and interactive elements work with keyboard and touch.
- [ ] Images use appropriate dimensions and delivery.
- [ ] Critical content remains usable when optional scripts fail.
- [ ] Ads, analytics, and consent behavior match explicit approvals.

## Final gate

- [ ] Production crawl completed.
- [ ] Representative rendered pages inspected.
- [ ] Build and validation commands passed.
- [ ] Deployment authorization recorded.
- [ ] Indexing authorization or default launch rule recorded.
- [ ] Post-launch review date scheduled.
