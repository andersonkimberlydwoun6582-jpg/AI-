# Website SEO SIIK

Draft reusable skill for planning and validating websites through research-backed architecture, keyword mapping, internal linking, content standards, and technical SEO gates.

## Current version

`0.1.0-draft`

This is not a frozen standard. It is the starting structure that will be expanded as new reports are reviewed and decisions are approved.

## How to use

1. Complete `INPUT_TEMPLATE.md`.
2. Process every supplied report through `REPORT_INGESTION.md`.
3. Record approved conclusions in `DECISIONS.md`.
4. Update the appropriate workflow module.
5. Use the files under `templates/` to produce project deliverables.
6. Run the checks in `SEO_VALIDATION.md` before indexing or launch.

## Suggested invocation

```text
Use the website-seo-siik skill.
Read the supplied report as a new source.
Extract claims, evidence, assumptions, and conflicts.
Do not promote unverified recommendations into rules.
Update the site architecture, keyword map, internal-link plan, content standards, validation rules, and decision log only after the conclusions are approved.
```
