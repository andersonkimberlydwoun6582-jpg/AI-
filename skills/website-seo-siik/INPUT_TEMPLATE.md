# Standard Input Template

Complete as much as possible. Unknown items should be marked `TBD`; do not invent them.

```text
Project name:
Repository:
Local project path:
Domain:
Site type: content / tool / directory / wiki / ecommerce / hybrid
Primary business goal:
Monetization model:
Target audience:
Primary countries or regions:
Target languages:

Main topic or product:
Official sources:
Existing site or reference sites:
Existing content directory:
Research reports:
Keyword data sources:
Analytics or Search Console access:

Core categories:
Required page types:
Known competitors:
Brand constraints:
Legal or policy requirements:

Indexing strategy:
Analytics:
Ads:
Deployment target:
Execution boundary: planning / local build / PR / merge / production deployment
```

## Minimum information for planning

- domain or provisional domain;
- topic, product, or game name;
- target audience and language;
- site type;
- available reports or keyword data;
- desired execution boundary.

## Minimum information for production deployment

- confirmed repository and deployment project;
- production domain ownership;
- environment-variable requirements;
- indexing decision;
- analytics decision;
- legal and trust pages;
- explicit deployment authorization.
